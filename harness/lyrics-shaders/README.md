# Lyrics shaders

`bash harness/lyrics-shaders/build.sh` compiles the production Metal source on the Mac's GPU and checks all five styles for distinct animated output, deterministic seeks, premultiplied glyph alpha, transparent backgrounds, intensity mixing with static ink, and the thermal/Low Power Mode frame-rate policy.

`bash harness/lyrics-shaders/preview.sh` builds and launches an isolated UIKit app on the booted iOS simulator. It uses the production renderer, draws all five styles with moving letters plus joined Arabic text, and checks invalid input, the mask budget, repeated invalidation, pause/resume, restoration of ordinary ink, and cleanup with GPU frames in flight. After three seconds the app writes `Documents/result.txt`. At twelve seconds it writes `Documents/performance.json` with successful effect-creation and main-thread tick durations, including periodic word replacement. These measure CPU submission work, not GPU completion or physical-device frame rates. The final stress test deliberately delays submissions and checks pause/seek cancellation, recovery, resize fallback and memory-pressure cleanup, then writes `Documents/stress-result.txt`. Allow at least fourteen seconds for all three files. Results from earlier launches are cleared on startup.

Use `xcrun simctl get_app_container booted com.taurus.lyricsshaders.harness data` to locate the files. The harness enables `SGR_LYRICS_SHADER_TESTING`; its delay hook is excluded from production builds. To compare an older renderer, set `SHADER_SOURCE` to its `.m` path (with matching headers alongside it) and `SHADER_TEST_FLAGS=-DSGR_LYRICS_SHADER_TESTING=0`; this disables assertions that depend on the new lifecycle behavior. End the preview with `xcrun simctl terminate booted com.taurus.lyricsshaders.harness`.

The five Metal fills are independently authored recreations of the visual styles named on Chroma's public lyrics preview (https://chroma.pw/). They are not extracted Chroma shader source and do not load Workshop content.

Device verification still needed: install the release on an iPhone running iOS 26+, enable Redesigned UI, open Mod Settings → Lyrics → Adjust → Lyrics shader, select each style, and play timed lyrics in portrait and landscape. Check the word sweep, letter motion, pause/resume, seeking, changing tracks and Reduce Motion. Classic returns to the original text. A hardware performance/battery comparison is not covered by this harness.
